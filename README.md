### 🎯 ¿QUÉ ES LEVIATÁN?

Es un sistema de control completo diseñado específicamente para la línea de equipos de **INMIMEX**:

- 📱 **Control remoto** desde celular o tablet
- 📷 **2 cámaras de monitoreo** — zona de llenado y producto terminado
- 🛡️ **Seguridad total** — bloqueo automático ante cualquier riesgo
- 🧹 **Limpieza automática programada** — sin exposición manual
- 📊 **Registro digital de cada lote** — trazabilidad completa
